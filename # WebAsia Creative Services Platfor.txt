## 1. Executive Overview

**WebAsia Creative Services Platform** is a SaaS-based, subscription-driven creative services marketplace inspired by platforms like **Kimp.io**, but deeply aligned with **WebAsia IT Solutions ([https://webasia.in/](https://webasia.in/))** brand identity, service offerings, and Indian market needs.

The platform converts WebAsia from a traditional service website into a **full-fledged CRM + Creative Workflow System**, where:

* Users explore services on the public website
* Register & subscribe to plans
* Access a CRM-style dashboard
* Submit unlimited creative requests
* Track progress, revisions, messaging, and deliveries

This system connects **Clients → Admin/Managers → Designers → Affiliates** in a controlled, scalable, and production-ready workflow.

## 5. Subscription & Credit Logic (IMPORTANT)

### Subscription-Based Access

Each plan provides:

* **Active request limit** (queue-based)
* **Monthly/weekly credits**
* **Service-specific caps** (videos, websites)

### Example Logic

| Plan     | Active Requests | Monthly Credits           |
| -------- | --------------- | ------------------------- |
| Startup  | 1               | 5 graphics                |
| Standard | 2               | 28 graphics + 4 videos    |
| Business | 3               | 90 graphics + 4 YT videos |

> Client can queue unlimited requests, but **only limited active requests** are processed at a time.

When a request is marked **Completed** → credit reduces → next queued request auto-activates.

## 6. Request Lifecycle (End-to-End)

### 6.1 Client Side

* Select service type (Graphic / Video / Web)
* Fill smart request form
* Upload references
* Set priority (Normal / Urgent)

### 6.2 Admin / Manager Side

* Request enters **Unassigned Queue**
* Manager assigns to designer
* SLA deadline auto-calculated

### 6.3 Designer Side

* Designer views task in dashboard
* Works on design
* Uploads version (v1, v2, v3...)
* Marks as **Submitted for Review**

### 6.4 Approval Flow

* Manager reviews output
* Approves OR sends back for rework

### 6.5 Client Review

* Client notified
* Uses annotation + comments
* Approves OR requests revision

### 6.6 Completion

* Final files delivered
* Request marked **Completed**
* Credits deducted
* Next request moves to active

Workflow & Process Flow
Request Lifecycle
Client Submission: Client fills AI-powered form, uploads references, sets priority

Auto-Assignment: System assigns to available designer based on workload and expertise
​

Designer Work: Designer downloads brief, creates design, uploads for internal review

Manager Approval: Manager reviews against brief, approves or requests changes

Client Review: Approved work moves to client portal with notification

Feedback Loop: Client provides feedback using annotation tools; work returns to designer if revisions needed

Final Delivery: Client approves final version; files move to download center; task marked complete

Queue Advancement: Next request in client's queue automatically moves to active status
